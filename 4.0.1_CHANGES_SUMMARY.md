## API Changes

### Added
- `AsyncWindowManager` class (Python)
- `ob_extension_hot_reload()` (C)
- `ob_extension_message_send()` (C)
- `obctl extension reload <name>` (CLI)

### Deprecated
- `WindowManager` sync API (Python) - Use AsyncWindowManager
- Direct signal usage - Use obctl

### Unchanged
- Configuration file format (rc.xml)
- Theme CSS format
- Key binding syntax
- D-Bus interface signatures

## Upgrade Path

### From 4.0.0
```
sudo apt update && sudo apt install openbox
# No configuration changes needed
```

### From 3.6
```
# Backup
cp -r ~/.config/openbox ~/.config/openbox-3.6-backup

# Install
sudo apt install openbox

# Convert themes
ob-theme-convert

# Update scripts (see MIGRATION.md)
```
